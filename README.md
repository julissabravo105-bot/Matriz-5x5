#Qué hace el programa?
Simula una sala de cine con 3 filas y 4 columnas. El usuario elige un asiento y el programa lo marca como reservado.
#¿Cómo usarlo?
Ejecuta el archivo 
Ingresa el número de fila (0, 1 o 2)
Ingresa el número de columna (0, 1, 2 o 3)
Se muestra el estado de la sala: 0 = libre, 1 = reservado
